# API-тесты TestBoard

Лабораторная Avito: создание объявлений и избранное.

## Как запустить

Нужны [Go 1.25.1 или новее](https://go.dev/doc/install), Git и
[golangci-lint v2](https://golangci-lint.run/docs/welcome/install/local/).

```bash
git clone https://github.com/msbezrukova12-maker/api-tests-student.git
cd api-tests-student
git switch main
go mod download
```

Создай в корне файл `.env.override` и укажи данные своего аккаунта TestBoard:

```dotenv
TEST_LOGIN=your_email
TEST_PASSWORD=your_password
```

Адрес API уже указан в `.env`. Файл `.env.override` не добавляется в Git.
Нужен доступ к [TestBoard](https://testboard.avito.com/).

Запуск из корня проекта:

```bash
go test -p 1 -count=3 ./...
golangci-lint run
```

Пакеты запускаются по очереди, тесты повторяются три раза. Прогон занимает несколько минут:
в тесте лимита создаётся 51 объявление, запросы идут с паузами.
Чтобы увидеть шаги, добавь `-v`:

```bash
go test -p 1 -count=1 -v ./tests/scenarios/advertisementCreate
```

## Что проверяется

- Создание со всеми полями, получение объявления, поиск по полному названию и фотографии.
- Границы из ЛР2: название из 50 символов, количество 100, без цены, одна и три фотографии.
- Ошибки обязательных полей, длины текста, цены, количества и формата фото.
- Отсутствующий и неверный токен.
- Добавление в избранное, удаление и исчезновение записи после удаления объявления.
- Несуществующий ID, повторное добавление, своё объявление и лимит 50 записей.
- Получение собственных объявлений.

Основа проверок создания — кейсы из `Безрукова_ЛР2.xlsx` (строки 25–38), избранное — из задания на API-тесты.
Тесты создают свои данные и удаляют объявления после проверки.
Для избранного регистрируются отдельные пользователи; удалить их через API нельзя.

Код разделён на Client → Manager → Scenario. Сценарии лежат в `tests/scenarios`.
По [Swagger](https://testboard.avito.com/swagger/index.html) получение и удаление объявления
работают через `/advertisement?id={id}`. В тексте задания этот путь записан иначе.

Для отладки запросов можно добавить `DEBUG=true` в `.env.override`.
В этом выводе могут быть токены и пароли — его не нужно публиковать.
